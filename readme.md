# ÁGORA - News Platform

Plataforma web de noticias desarrollada como prototipo funcional
para la Entrega 2 del módulo Front End.

ÁGORA permite explorar noticias, consultar su información,
filtrarlas por categorías y guardar noticias favoritas para
consultarlas posteriormente.

---

## Descripción

ÁGORA es una plataforma web enfocada en la consulta y
organización de noticias.

El proyecto cuenta con una interfaz clara y adaptable a
diferentes tamaños de pantalla, además de funcionalidades
interactivas desarrolladas con HTML, CSS y JavaScript.

Las noticias se cargan dinámicamente desde un archivo JSON
local.

---

## Funcionalidades

- Página de inicio con noticias destacadas.
- Listado completo de noticias.
- Visualización del detalle de cada noticia.
- Filtrado de noticias por categorías.
- Sistema de favoritos.
- Persistencia de favoritos mediante `localStorage`.
- Formulario de contacto con validaciones.
- Diseño responsive.
- Navegación entre las diferentes secciones de la plataforma.
- Carga dinámica de información desde JSON.
